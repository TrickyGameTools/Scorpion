# Scorpion

### Status: WIP

Scorpion will be simple tool you can use to play games written in Scyndi's Creative Interpreter.
All Scorpion needs will be the .JCR files. The specific SCI_Run executables should be available to Scorpion is "dependencies", although as Scorpion will come as .AppImage for Linux and have the SCI_Run exe files in the same dir in the basic Windows installation, no real trouble... right?
Multiple versions could be covered.
